# Project notes

This portfolio dashboard explores correlations among average property, societal, and personal crime rates and maps ten-year average crime rates by King County city. The design uses a correlation matrix, scatterplots with Pearson's *r* and confidence bands, and a labeled map emphasizing the five highest-rate cities. The published artifact is a static export; the original interactive controls are not included.

Source provenance: Washington State Statistical Analysis Center (WSSAC). See `README.md` for limitations and reuse guidance.
